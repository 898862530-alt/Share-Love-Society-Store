# 爱分你联名商城 · 设计标准 v0.2

移动端优先，以 390 CSS px 为设计基准，验证 320 / 375 / 390 / 430px。桌面内容也限制在 480px，延续同一套手机排版。既有页面结构与浏览路径保留。

## 规范依据

- [Apple HIG · Typography](https://developer.apple.com/design/human-interface-guidelines/typography)：使用清晰的语义字号层级，默认 iOS 正文为 17pt，并验证较大文字的阅读体验。
- [Apple HIG · Layout](https://developer.apple.com/design/human-interface-guidelines/layout)：统一对齐、留出控件空间，通过露出下一张卡片提示横向滚动。
- [Apple HIG · Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：保证文字对比度、足够的触控区域及大字模式下的可读性。

以下 CSS px、rem、中文行高与间距为本项目的网页适配决策，并非宣称与 iOS pt 或原生 Dynamic Type 完全等价。未照搬 Apple 的原生材质与控件。

## 全局设计变量

所有页面引用 `src/styles/tokens.css`。后续修改优先调整变量，不再为同一语义单独指定字号或颜色。

| 语义 | 默认字号 | 使用场景 |
| --- | --- | --- |
| Large title | 34px | 页面主标题、商品名、发现标题 |
| Title 1 | 28px | 章节标题、联名主题、故事标题 |
| Title 2 | 22px | 新品卡片副标题 |
| Title 3 | 20px | 商品列表名称、作品名称、段落小标题 |
| Body | 17px | 故事与产品正文、导航标题、主按钮 |
| Secondary | 15px | 类目名称、商品说明、辅助介绍 |
| Footnote | 13px | 规格提示、作品作者、演示说明 |
| Caption | 12px | 英文标签、底部 Tab、辅助标识 |

- 中文标题行高 1.3；长正文 1.65；辅助说明 1.5。字重只用 400 / 500 / 600 / 700，正文不使用过淡颜色。
- 默认页面左右边距 20px，375px 及以上为 24px。页面标题、章节标题、卡片与正文共用对齐线。
- 间距使用 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64px；常规章节间距 48px，故事段落上下 64px。
- 主卡片圆角 24px，缩略图 16px，按钮 12px。主按钮最小高 52px，独立点击区域至少 44 × 44px。
- 导航栏最小高 56px，底部栏默认高 64px，均考虑安全区。固定底栏下方预留滚动空间。
- 横滑商品卡片：小屏宽 256px，375px 以上宽 280px。默认图高 240px；同一行卡片等高、信息对齐，并露出下一张卡片。
- 新品卡片采用自然内容高度，文字、照片、底部信息依次排列，文字换行时不覆盖商品图。
- 列表缩略图为 108 × 144px / 120 × 160px，商品名称允许换行。不同类别共用同一列表组件样式。
- 移除各详情页重复的 SLS 角标，让返回与居中页面标题成为统一导航。

## 颜色与可读性

| 变量 | 色值 |
| --- | --- |
| 主要文字 | #222721 |
| 次要文字 | #515b50 |
| 注释文字 | #60695d |
| 品牌强调 | #315b43 |
| 页面底色 | #f5f5f2 |
| 白色表面 | #ffffff |
| 浅绿表面 | #eaf0e6 |
| 分隔线 | #dde2d9 |

主要文字、辅助文字与注释在白、暖灰、浅绿、新品卡片底色上的对比度均不低于 4.5:1。包装上的微小文字属于商品概念插画，不承载界面操作或必要商品信息，且对辅助阅读隐藏。

H5 字体使用 rem，根字号保留浏览器默认值，覆盖 uni-app 按视口修改根字号的行为；页面默认字号不会随手机宽度整体缩放。允许浏览器缩放，未限制 maximum-scale。为验证大字布局，曾在开发环境临时将根字号设为 200%，检查后恢复 100%。这不等同于原生 iOS Dynamic Type 支持。小程序使用相同默认 px 字号，仍需真机验证系统文字设置与 CSS 支持。

减少动态效果偏好下缩短非必要过渡。导航保留标签和选中状态，独立返回按钮有可访问名称。原生组件的默认边框、行高被统一重置，避免不同构建模式下出现视觉差异。

## 页面与交互
- 底部仅发现、商城。默认商城；发现暂只有大标题。
- 商城：首页分类 3 项 → 新品 2 张 → 咖啡、烘焙、服装各 4 张横滑卡片 + 了解更多 → 一整段合作介绍。
- 分类：咖啡 7 款，烘焙 7 款，服装 4 个明确标注的概念款。纵向列表，不伪造售卖状态。
- 产品：基础信息 → 合作主题 → 8 幅错位作品 → 对应作品与产品的专属页面。
- 作品专属页：白墙木框 → 故事 → 合作关系 → 产品摘要与返回详情链接。

## 内容依据与待补项
- 咖啡 Word 仅有伊真、马利诺、展玉、托拉雅、特芒贡五款。以用户明确提到的加约补足第六款，再加猫屎咖啡，共七款。
- 加约、猫屎咖啡的产地、处理、风味、规格待确认。
- 马利诺和特芒贡豆种存在原资料提醒；不展示未经确认的 Arabica/Robusta 信息。特芒贡处理方式为原文建议，前端先不作确定宣称。
- 烘焙名称、食材、工艺来自用户图片；产品图为从资料图提取的低分辨率图片，后续需替换高清授权素材。
- 未提供售价、重量、库存、购买链路，均未虚构。
- 未提供服装商品，当前为四个概念占位款。
- 所有八幅作品是 AI 生成演示素材；作品名与故事为演示文案，作者仅使用明确占位标识；不声称是孤独症艺术家的真实作品。
- 生成图片提示词见 image-prompts.json，使用内置 imagegen。
