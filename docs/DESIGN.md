# 爱分你移动商城 · v3 设计说明

## 导航与内容

- 首页为主推产品轮播：展玉、加约、福州茉莉茶酥。下方只有“商城中心”和“我的”两个入口，首页首屏不显示底部导航。下滑后浮出导航；点击入口时，两个按钮收拢至对应底部 tab，选中后进入相应页面。
- 首页按可用窗口高度分为五屏，一次手势推进一屏；继续下滑，依次阅读创始与理念、孤独症科普、画展、加入爱分你四个分屏章节。创始人、创立日期、真实展览记录和联系方式待团队提供。
- 商城保留分类横栏、两个新品卡片、三类产品的横向推荐与公益介绍。商城、类别、个人页使用“首页 / 商城 / 我的”底部导航。
- 7 款咖啡、7 款烘焙、4 款服装概念产品均包含四个详情章节：产品概览、产地或食材、风味或工艺、艺术联名。
- 每款产品提供 8 幅演示作品，作品进入木框画廊、故事、联名关系和关联商品页面。作品选择保持当前商品和作品的对应关系。
- 收藏、购物车、演示订单保存在本机。选作品与规格 → 加购物车或立即选购 → 虚构收货资料 → 演示订单完成 → 我的订单。无真实支付、扣款、库存与物流。

## 视觉规范

以设计师提供的白底、蓝色细线、产品大图和轻松人物插画为新方向，延续此前移动端的字号、间距和触控规范。

- 内容最大宽度 480px，页面左右留白 20px，375px 起为 24px。
- 字号使用 34 / 28 / 22 / 20 / 17 / 15 / 13 / 12px。正文行高 1.65，长篇品牌介绍为 1.8。H5 使用 rem 响应浏览器文字大小偏好。
- 正文深蓝灰 `#183a4d`，次要文字 `#496474`，弱提示 `#5d7482`，交互蓝 `#126fa4`，视觉蓝 `#2389c4`。
- 白色主背景，`#edf7fd` 浅蓝分区。卡片圆角 24px，按钮 14px，页面章节保留宽松留白。
- 常规按钮至少 52px 高，图标和轮播指示点的触控范围至少 44px。底部操作栏和导航适配安全区。
- 首页不自动播放轮播，用户可滑动或点指示点，减少阅读被打断。减少动态效果的系统偏好继续生效。

## 可替换数据与素材

- `src/data/catalog.ts`：商品基础资料、8 幅作品信息。
- `src/data/editorial.ts`：三款主推、逐款详情文案与演示规格。
- `src/stores/commerce.ts`：本机收藏、购物车、演示订单及结算草稿。
- `src/static/assets/campaign-*.webp`：三张新主推概念图，由设计参考生成；提示词见 `docs/image-prompts-v3.json`。
- 作品图均为 AI 占位图，不代表真实孤独症艺术家的创作。作者、个人故事、作品授权与公益支持机制待替换和确认。
- 商品价格、净含量、部分咖啡参数、食品配料与过敏原、服装材质尺码等待正式资料。演示规格明确标注，不可作为正式售卖参数。
- 科普内容参考世界卫生组织：https://www.who.int/zh/news-room/fact-sheets/detail/autism-spectrum-disorders 。仅提供简短理解入口，不涉及诊断、疗效或个体医疗建议。

## 验证与发布

类型检查、GitHub Pages 子路径构建、微信小程序构建通过。浏览器验证覆盖 320px 和 390px 手机布局、18 款详情链接、8 幅作品、当前作品选购、数量同步、表单校验、订单完成与刷新后记录保留。

正式微信版本仍需配置 AppID，使用微信开发者工具与真机检查。当前继续保持 uni-app 组件与导航接口；未引入仅支持 H5 的商业逻辑。图标 SVG data URI 与部分 CSS 画框、包装效果需在真机确认。

## 微信导航与分页更新

顶部控件带由 `MiniChrome` 与共享窗口布局 统一预留。微信版结合窗口、状态栏和胶囊矩形计算可用区域，不再仅依赖 CSS 的刘海安全区。次级页自己的返回栏位于该区域下方。H5 以 46px 控件带作版式预览，不模拟设备的真实状态栏。

首页使用纵向 `swiper`，首屏内使用横向产品 `swiper`；不同方向的操作分别处理。窗口变化时重新测量，普通手机尺寸每屏可完整阅读。极矮窗口或放大文字时，允许在当前章节内补充滚动，章节按钮和底部导航继续可用。

详细依据、边界与验证见 `docs/WECHAT-INTERACTION.md`。
